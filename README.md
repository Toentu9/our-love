# Our Cute Love Story ♡

Website kỷ niệm tình yêu được xây dựng bằng HTML, CSS và JavaScript thuần.

## Cấu trúc

- `index.html` — nội dung và cấu trúc các màn hình.
- `style.css` — giao diện, màu sắc và hiệu ứng.
- `script.js` — chuyển màn hình, hiệu ứng cây trái tim và album.
- `assets/childhood/` — ảnh tuổi thơ của hai bạn.
- `assets/memories/` — 19 ảnh kỷ niệm.

## Chạy trên máy

Mở `index.html` bằng Chrome, Edge hoặc Opera.

## Đưa website lên GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Giải nén gói này trên máy.
3. Upload **toàn bộ nội dung bên trong thư mục này** lên thư mục gốc của repository (đảm bảo `index.html` nằm ngay ở thư mục gốc, không nằm trong một thư mục con).
4. Vào **Settings → Pages**.
5. Trong **Build and deployment**, chọn **Deploy from a branch**.
6. Chọn branch `main`, folder `/ (root)`, rồi bấm **Save**.
7. Đợi GitHub triển khai và mở đường link Pages được hiển thị trong mục Pages.

## Chỉnh sửa

- Sửa nội dung và lời thư trong `index.html`.
- Sửa màu sắc, bố cục và animation trong `style.css`.
- Sửa hành vi tương tác và danh sách ảnh trong `script.js`.
- Thay ảnh bằng cách giữ nguyên tên file trong `assets/` để các đường dẫn không bị hỏng.
